# SOC-Homelab-BlackFalcon
Operation BlackFalcon is an 8 weeks hands-on SOC lab simulating a cyber intrusion against a fictitious government contractor. From Active Directory and SIEM monitoring to threat hunting and incident response, I build, attack, detect and defend the environment.

My main goal here is to gain hands-on experience across a wide range of cybersecurity concepts, understand how they work, and develop the ability to apply them naturally while thinking and responding like a real cybersecurity professional.

Roadmap for the next 8 weeks:
Week 1 — Infrastructure
    Build the virtual lab
    Configure networking
    Deploy Windows Server
    Deploy Windows workstation
    Document architecture

Week 2 — Active Directory
    Configure the domain
    Create users and groups
    Configure GPOs
    Implement basic permissions

Week 3 — Telemetry
    Deploy Sysmon
    Configure Windows logging
    Deploy Wazuh agents
    Validate log ingestion

Week 4 — SIEM & Detection
    Build dashboards
    Create detection rules
    Investigate Windows security events
    Establish a baseline

Week 5 — Attack Simulation
    Execute the controlled attack scenario
    Generate security telemetry
    Document the attack chain

Week 6 — Threat Hunting
    Develop hunting hypotheses
    Search for attacker activity
    Correlate endpoint and authentication data
    Map findings to MITRE ATT&CK

Week 7 — Incident Response
    Perform triage
    Contain the compromised host
    Investigate persistence
    Recover the environment
    Produce an incident report

Week 8 — Validation & Portfolio
    Replay the attack
    Validate detections
    Improve documentation
    Finalize GitHub repository
    Produce a project walkthrough
